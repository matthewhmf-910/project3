# 字體排版規格表（Typography Spec）

畫布：1080 × 1920 px，30 fps。所有數值以 px 計（1080 寬畫布）。
字型檔已下載到 `fonts/`，全部係 Google Fonts，開源（OFL），商用免費。
樣板圖：`type_specimen.png`（左：段中排版；右：菜名小窗 + 收尾 end card）。

## 3. 顏色

| Token | 色值 | 用途 |
|---|---|---|
| white | `#FFFFFF` | 所有主要文字 |
| cream | `#F2E6D0` | 註記文字 |
| tea gold | `#C9A45C` | 細線、對位角標（取自杯墊 logo 嘅金色） |
| line | `rgba(255,255,255,.6)` | 小窗 1px 外框 |
| scrim | 上 35% → 透明 → 下 55% 黑色漸變 | 保證白字睇得清 |

## 4. 位置與安全區

- 頂部 **0–220** 同底部 **1540–1920** 唔放字（IG / 抖音 / 小紅書 UI 會遮住）。
- 左右邊距 **72**，文字闊度最多 **936**。
- 主標題組（T3 + T1 ZH + T1 EN）靠左，**底部對齊 y = 1520**。
- 註記（T4）放喺左上 **(72, 252)**。
- 手寫字（T2）放喺畫面中段，盡量貼住動作位（例如倒茶嗰條茶線旁邊）。
- 同一時間畫面最多 **兩層** 文字（T4 註記唔計）。

## 5. 編排元素

| 元素 | 規格 |
|---|---|
| 圖片小窗 | 1px `line` 外框；比例 4:5 或者 3:4；同畫面邊距 72 |
| 對位角標 | 22×22 L 形，1px tea gold，放喺小窗對角，向外偏 10 |
| 分隔線 | 1px，tea gold 或者 white 60%，長 48–120 |
| 菲林顆粒 | 單色 noise，不透明度 4–6% |

## 6. 動畫參數（30 fps）

| 層 | 入場 | 停留 | 出場 |
|---|---|---|---|
| T1 ZH / EN | 由下向上遮罩揭示，**12f**，ease-out（cubic-bezier .2,.8,.2,1）；EN 延遲 **4f** | 最少 45f | 向上移 40px + 淡出，**8f** |
| T2 手寫 | 筆劃寫出（stroke write-on）**20–24f** | 30f+ | 淡出 10f |
| T3 副標 | 逐個字母淡入，每個延遲 **1f** | 同 T1 | 同 T1 |
| T4 註記 | 金線由左畫出 **8f**，跟住文字淡入 **6f** | 成個鏡頭 | 硬切 |
| T5 菜名 | 小窗外框畫出 **10f** → 圖片揭示 **12f** → 文字向上 **10f** | — | 跟小窗一齊滑走 |
| T6 店名 | 字距由 +0.30em 收到 +0.08em，**24f**，ease-out | 到片尾 | — |
