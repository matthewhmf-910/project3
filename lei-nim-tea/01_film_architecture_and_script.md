## 2. 三段結構

```
0s ─────────── 10s ─────────── 20s ─────────── 30s
│ SEG 1 入門     │ SEG 2 茶入饌    │ SEG 3 夜・茶    │
│ 好奇           │ 期待 → 滿足     │ 回味           │
│ 紅霓虹・茶餅   │ 篩粉・倒茶 HERO │ 茶調酒・夜景   │
└── 圓形茶餅 ──→ 圓形茶碗          │
                 └── 傾倒液體 ──→ 杯中酒色        │
                                   └── 杯墊 logo end card
```

### SEG 1｜入門 Step Inside（0–10s）
- **目的：** 用空間同茶具勾起好奇心：「呢度唔係普通茶餐廳」。
- **素材：** `01` 紅霓虹入口、`10` 旋轉樓梯、`08` 普洱茶餅、`09` 茶磚盒/錫罐、`06` 用餐區
- **鏡頭草案：**
  1. 紅色霓虹字直向 tilt-up，紅光掃過（hook）
  2. 入口全景，天花圓孔圖案向前推
  3. 分屏：茶磚盒 macro ｜ 錫茶罐
  4. 旋轉樓梯向上 parallax（cursive：*step inside*）
  5. 推近普洱「龍」字茶餅，**圓形** 填滿畫面 → 交畀 SEG 2
- **畫面文字：**「有啲茶，要行入嚟先飲到。」/ *Some tea, you have to step inside for.*

### SEG 2｜茶入饌 Tea at the Table（10–20s）
- **目的：** 茶唔止喺杯入面：佢係調味、係湯底。
- **素材：** `02` 篩抹茶、`03` HERO 倒茶、`04` 豉油雞、`13` 全枱、`11` 分層茶拿鐵
- **鏡頭草案：**
  1. 由茶餅 **圓形** match cut 去茶碗口：抹茶粉篩落（慢鏡）
  2. 全枱俯視，editorial 小窗標註：`[魚飯菜名]`、`[雞菜名]`
  3. **HERO：** 茶倒落魚飯，40% 慢鏡，hold 最耐（cursive：*pour*）
  4. 豉油雞 + 蔥絲 macro 推近
  5. 分層茶拿鐵，液體分層 → 由液面 **傾倒動作** 交畀 SEG 3
- **畫面文字：**「篩、倒、浸：茶，不止一杯。」/ *Tea, beyond the cup.*

### SEG 3｜夜・茶 By Night（20–30s）
- **目的：** 入夜，茶變成酒，用回味收尾。
- **素材：** `07` 茶調酒（紫花）、`12` 茶調酒 + 夜街、`05` menu 牆、`11` 杯墊 logo
- **鏡頭草案：**
  1. 酒杯液面接住上一段嘅液體，紫色食用花轉動
  2. 酒杯 + 街燈 bokeh，light leak 表示日轉夜（**crop 走麥當勞**）
  3. menu 牆 editorial 小窗快閃（G/F 外賣都有得飲）
  4. 第二杯茶調酒 rack focus，由街景拉返杯（cursive：*linger*）
  5. **End card：** 杯墊金色 logo 推近 + 店名 + `[地區]` + 樓層資訊
- **畫面文字：**「夜晚，茶變成另一種醉。」/ *By night, tea becomes something else.*
- **End card：** 離念・茶蒔 ｜ `[地區], HONG KONG` ｜ G/F TAKEAWAY · 1/F RESTAURANT & TEA COCKTAIL
