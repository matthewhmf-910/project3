# 教學模式：一張參考圖點樣變成 code 入面嘅參數

用嚟做例子嘅係你條參考片（「Make a Pause」，720×1280，24fps）。
文件入面每個數字都係用程式真實量出嚟，唔係用眼估。對照圖：

- `01_spacing_typography_measured.png`：空間同字體排印嘅實測標註
- `02_lighting_measured.png`：光影實測，參考片同我做嘅並排比較

---

## 0. 成個流程（四步）

```
① 睇        →  ② 量             →  ③ 翻譯成參數          →  ④ 對比驗證
認出有咩元素     用程式數像素、       換算到 1080×1920，       出一格同參考片並排，
（字、格、光）   計顏色同時間        寫入 code               再量一次，睇差幾多
```

**之前做唔好，係因為跳咗第 ② 同第 ④ 步。** 我直接由「睇」跳去「寫 code」，所以數字全部靠估。
今次補返實測之後，就發現我 10 秒片入面有幾個數仍然有偏差（見下面每節嘅 ✗）。

換算規則：參考片係 720 闊，成品係 1080 闊，所以**所有長度 × 1.5**。

---

## 1. SPACING 空間佈局

**② 點樣量：** 揀出接近純黑嘅像素（RGB 全部 < 28）。成行都係黑嘅位就係格與格之間嘅空隙，成列都係黑嘅位就係左右兩邊嘅黑邊。

| 元素 | 參考片實測 | × 1.5 應該係 | 我而家 code 入面 | 判斷 |
|---|---|---|---|---|
| 菲林格闊 | 666 | 999 | `FW = 1001` | ✓ |
| 菲林格高 | 425 | 637 | `FH = 627` | ✗ 矮咗 10 |
| 格與格空隙 | **8** | **12** | 21（627 + 21 = 648） | ✗ 闊咗差不多一倍 |
| 左邊齒孔位 | 31 | 46 | `FX = 42` | ≈ |
| 中格頂 | 426 | 639 | `FRAMES_Y[1] = 645` | ≈ |

📍 參數位置：`video/src/FilmRef10.tsx:16-20`

**呢個數字點解重要：** 格與格之間嘅空隙只係 8px，菲林睇落先會係一條連續嘅膠片。空隙一闊，就會變成三張分開嘅卡。呢個係我用眼估唔出嘅差別。

---

## 2. TYPOGRAPHY 字體排印

**② 點樣量：** 喺中間嗰格揀出接近純白嘅像素（RGB 全部 > 225），計佢哋嘅外框，再逐行統計，搵出每行字嘅上下界。

| 元素 | 參考片實測 | × 1.5 | 我而家 | 判斷 |
|---|---|---|---|---|
| 字塊大細 | 314 × 160 | 471 × 240 | 約 450 × 224 | ✗ 細咗大約 5% |
| 字高（Pause 個 P） | 68 | 102 | 97 | ✗ |
| 行距（行頂到行頂） | 92（= 1.33 × 字高） | 138 | 127 | ✗ 太密 |
| 字塊水平中心 | 比格中心**偏左 16** | 偏左 24 | 置中 | ✗ |
| 字塊垂直中心 | 634.5（格中心 638） | — | 950（目標 952） | ✓ |
| 字塊闊佔格闊 | 47% | — | 45% | ≈ |

**③ 換算成 CSS：**
- 字型 Nunito Sans 嘅字高大約係字號嘅 0.705 倍，所以 `fontSize = 102 ÷ 0.705 ≈ 145`（而家係 138）。
- `lineHeight = 138 ÷ 145 ≈ 0.95`（而家係 0.92）。
- 水平位置加 `translateX(-24px)`。

📍 參數位置：`video/src/FilmRef10.tsx:88-90`

---

## 3. FONTS 字體選擇

**呢一項唔係量度，係判斷。** 我嘅做法係睇字形特徵，再喺免費字型入面搵最接近嘅：

| 特徵 | 參考片 | 推論 |
|---|---|---|
| 「a」 | 雙層 a（上面有個勾） | 排除 Futura 呢類幾何字 |
| 筆畫末端 | 微圓、粗細一致 | 人文無襯線字（Avenir、Nunito Sans 呢類） |
| 字重 | 好粗但唔係最粗 | 700–800 |
| 字距 | 偏緊 | letter-spacing 大約 −1.5% |

**結論：** 原片好可能用咗 Avenir Next 或者手機剪片 App 內置嘅字型（例如 CapCut）。最接近嘅免費字型係 **Nunito Sans 800**。

**誠實講：** 字型名稱冇辦法由像素百分百確認。如果你知道原片用咩 App 剪，話我知，我可以縮窄範圍。

---

## 4. LIGHTING 光影

**② 點樣量：** 將每格轉做亮度，再計以下五個數：

| 指標 | 意思 |
|---|---|
| 平均亮度 | 成格整體偏光定偏暗 |
| 標準差 | 對比強弱 |
| 暗部 p5、光部 p95 | 最暗嗰 5% 同最光嗰 5% 有幾暗、幾光 |
| 平均飽和度 | 顏色鮮唔鮮 |
| 紅 ÷ 藍 | 冷暖。數字愈大愈暖 |

| | 參考片 | 我做嘅 | 差別 |
|---|---|---|---|
| **開場菲林**：飽和度 | **0.19** | 0.34 | 我鮮咗差唔多一倍 |
| 開場菲林：冷暖 | **1.10**（中性偏冷） | 1.54 | 我暖好多 |
| 開場菲林：平均亮度 | 64 | 86 | 我光咗 |
| **全屏鏡頭**：暗部 p5 | **32** | 5 | 參考片最暗嘅位都唔係全黑，即係所謂「褪色 / matte」感 |
| 全屏鏡頭：飽和度 | 0.48 | 0.66 | 我鮮咗 |

**③ 換算成調色參數：**
- 開場菲林：`saturate(0.55) brightness(0.8)`，再減少暖色。而家只係 `saturate(.9)`，喺 `FilmRef10.tsx:44`。
- 全屏鏡頭：加一層「提亮暗部」，令最黑嘅位提高大約 30；飽和度乘 0.75。

**限制要講清楚：** 一張相嘅光源方向同影子已經拍定咗，我冇辦法重新打光，只可以做調色，即係改亮度、對比、顏色。另外，參考片嘅全屏鏡頭係日光街景，我嘅係室內，內容唔同，所以只可以拉近整體色調，做唔到一模一樣。

## 5. 點解今次可以講得出原因

| 之前 | 今次 |
|---|---|
| 「我覺得似」 | 「我量到係 8px，我寫咗 21px，差咗 13」 |
| 改完靠你話啱唔啱 | 改完再量一次，數字對得上先畀你睇 |

## 6. 喺新對話開教學模式

將下面呢段貼入一個新對話，再附上參考圖或者參考片：

```
教學模式。我會畀你一張參考圖（或片）同我嘅素材。
請你唔好直接出成品，先逐步做：
1. 列出參考入面有咩元素（字、格、圖、光）。
2. 用程式實測以下四個維度，每個數字講埋點樣量出嚟：
   TYPOGRAPHY（字塊大細、字高、行距、位置）
   SPACING（邊距、空隙、比例）
   FONTS（字形特徵 → 推論字型，講明邊啲係估）
   LIGHTING（亮度、對比、暗部光部、飽和度、冷暖）
3. 將每個數字換算成 code 參數，寫明喺邊個檔案邊一行。
4. 出一格同參考並排，再量一次，列出仲差幾多。
每完成一步就停低，等我確認先繼續。
```
